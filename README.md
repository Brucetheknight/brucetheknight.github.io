# Brucetheknight // Personal Portfolio

赛博朋克风格的交互个人主页：进入霓虹街区，探索 AI 科研工具、显微图像分析与创意网页项目。

- 三维街区：拖动旋转、滚轮或双指缩放、点击建筑打开项目。
- 项目矩阵：分类、详情、源码链接与已确认的在线体验入口。
- 响应式布局，支持键盘操作与系统减少动态效果设置。

项目介绍依据 2026-10-10 的公开仓库内容整理。概念封面与实际网站截图均有区分，未展示未经验证的性能或科研成果。

`index.html` 为自包含静态网页，全部视觉资源与 Three.js 已内联。Three.js 使用 MIT 许可，其许可文本保留在文件中。该主页由 AI 辅助设计与实现。
